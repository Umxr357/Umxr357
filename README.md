## 🚀 Featured Projects

### 🎧 [Xplode](https://github.com/Umxr357/xplode)

An interactive product experience showcasing the Sony WH-1000XM6 through scroll-driven, exploded-view storytelling.

- Image sequences reveal the headphones' internal components as the page scrolls.
- Responsive presentation built with **React, Next.js, TypeScript, and Tailwind CSS**.

[View source →](https://github.com/Umxr357/xplode)

### ✍️ [Marginly](https://github.com/Umxr357/marginly)

A blog platform with an editorial interface and persistent posts.

- Account sessions, draft and publish workflows, bookmarks, likes, and comments.
- Built with **Next.js, React, TypeScript, and PostgreSQL**.

[View source →](https://github.com/Umxr357/marginly)

### 🌌 [N-body Simulator](https://github.com/Umxr357/n-body-simulator)

A browser-based gravity sandbox for exploring how bodies interact under gravity.

- Numerical integration options, collision handling, and energy diagnostics.
- Built with **JavaScript, HTML, CSS, and Canvas**.

[View source →](https://github.com/Umxr357/n-body-simulator)

### 🛒 [Amazonclone](https://github.com/Umxr357/Amazonclone)

An Amazon-inspired storefront interface built with **HTML and CSS**, featuring navigation, a hero section, and product grids.

[View source →](https://github.com/Umxr357/Amazonclone)
